## 1. ภาพรวมโครงการ (Project Overview)

CASHBOARD เป็นระบบสารสนเทศสำหรับติดตาม ควบคุม กำกับ และประเมินผลการดำเนินงานธุรการและบริหารทั่วไปของสำนักตรวจเงินแผ่นดินจังหวัดสุรินทร์

ระบบออกแบบให้เจ้าหน้าที่สามารถบันทึกและปรับปรุงข้อมูลผ่าน Google Sheets โดยข้อมูลจะถูกนำมาแสดงบนเว็บไซต์ CASHBOARD ซึ่งเผยแพร่ผ่าน GitHub Pages

ระบบมุ่งเน้นการลดภาระการจัดทำรายงานซ้ำซ้อน เพิ่มประสิทธิภาพการติดตามงาน และสนับสนุนการตัดสินใจของผู้บริหารด้วยข้อมูลที่เป็นปัจจุบัน

### 🎯 วัตถุประสงค์

1. พัฒนาระบบติดตามงานธุรการและบริหารทั่วไปแบบรวมศูนย์
2. ใช้ Google Sheets เป็นฐานข้อมูลหลัก
3. รองรับการเชื่อมต่อ Google Sheets หลายไฟล์และหลายชีต
4. ลดการจัดทำรายงานและการรวบรวมข้อมูลด้วยมือ
5. แสดงผลการดำเนินงานผ่าน Dashboard ผู้บริหาร
6. ติดตามงานค้าง งานเกินกำหนด และงานเร่งด่วน
7. ประเมินผลการปฏิบัติงานตามตัวชี้วัด KPI
8. สนับสนุนการบริหารงานด้วยข้อมูลที่ตรวจสอบย้อนกลับได้

## 7. ระบบเชื่อมต่อ Google Sheets

### Multi-Sheet Data Connector

ระบบมีเป้าหมายให้รองรับ

* Google Sheets หลายไฟล์
* หลายชีตภายในแต่ละไฟล์
* การกำหนดแหล่งข้อมูลตามหมวดงาน
* การจับคู่ชื่อคอลัมน์
* การรวมข้อมูล
* การตรวจสอบความถูกต้อง
* การคำนวณ KPI
* การติดตามสถานะการซิงก์

### การรีเฟรชข้อมูล

ค่าเริ่มต้นของเว็บไซต์กำหนดให้ตรวจสอบข้อมูลใหม่ทุก 30 วินาที

```javascript
const CONFIG = {
  apiUrl: "",
  refreshInterval: 30000,
  demoMode: true
};
```

เมื่อพัฒนา Backend และตรวจสอบระบบความปลอดภัยแล้ว สามารถเปลี่ยนเป็น

```javascript
const CONFIG = {
  apiUrl: "YOUR_SECURE_BACKEND_API",
  refreshInterval: 30000,
  demoMode: false
};
```

การรีเฟรชทุก 30 วินาทีเป็นการดึงข้อมูลตามรอบ ไม่ใช่การรับประกันการแสดงผลแบบเรียลไทม์ทันที

## 10. ระบบสิทธิ์ผู้ใช้งาน

กำหนดบทบาทผู้ใช้ 4 ระดับ

| Role       | สิทธิ์                           |
| ---------- | -------------------------------- |
| Director   | ดูภาพรวมและอนุมัติงาน            |

ข้อกำหนดสำคัญ ได้แก่

1. ใช้ Google Sheets ที่ได้รับอนุญาตเท่านั้น
2. จำกัดสิทธิ์การเข้าถึงตามหน้าที่
3. ไม่เผยแพร่ข้อมูลภายในผ่าน API สาธารณะ
